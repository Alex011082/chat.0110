# Политика конфиденциальности CHAT.0110 — проект

Проект от 5 ноября 2026 года. Подготовлен для рассмотрения издателем; не опубликован и не действует как утверждённая политика.

**Издатель:** Alex Davidov. **Контакт по вопросам данных и поддержки:** alexdavidov127@gmail.com.

CHAT.0110 связывает выбранные пользователем GitHub-чаты с его приложениями ИИ. Общий удалённый MCP работает на сервере CHAT.0110; установка локального сервера для этого подключения не требуется.

## Какие данные обрабатываются

При входе через GitHub сервис получает идентификатор и логин подключённого аккаунта и данные авторизации, необходимые для разрешённых действий. При работе с чатом обрабатываются выбранный репозиторий и ветка чата, сообщения и ответы, их авторы и время, а также служебные идентификаторы участников, заданий, очередей и подтверждений публикации.

MCP использует доступ подключённого аккаунта GitHub. Чтение и публикация дополнительно проверяются по доступу к репозиторию и состоянию чата. Подключение к CHAT.0110 само по себе не предоставляет доступ ко всем файлам компьютера пользователя.

## Для чего нужны данные

Данные используются для входа, чтения выбранных разговоров, доставки адресованных заданий, публикации законченных ответов в тот же GitHub-чат и сохранения состояния задания при повторном запросе. Служебные идентификаторы позволяют продолжить работу прежнего участника и избежать повторной публикации одного ответа.

Текст проходит автоматическую проверку на распознаваемые секреты и персональные данные перед дальнейшей передачей или публикацией. Такая проверка не гарантирует обнаружение всех чувствительных данных.

## Где находятся данные и кому они передаются

Сообщения и опубликованные ответы хранятся в ветках и pull request GitHub. Их видимость определяется доступом к соответствующему репозиторию GitHub.

На сервере CHAT.0110 хранятся служебные данные авторизации, участников и заданий. При обращении к MCP разрешённый контекст передаётся выбранному пользователем приложению ИИ. GitHub и выбранный поставщик ИИ обрабатывают полученные ими данные по собственным условиям и политикам.

## Управление доступом и удаление

Пользователь может отключить участие конкретного ИИ в чате и отозвать подключение в настройках приложения. Отключение и повторное подключение не являются командой удалить историю GitHub или возобновить остановленные задания.

Удаление плагина не удаляет уже опубликованные сообщения, коммиты и историю GitHub. Для управления этой историей используются средства GitHub и права владельца репозитория. Вопросы о данных, находящихся на сервере CHAT.0110, можно направить издателю по указанному выше адресу.

## Что требуется утвердить до публикации

Издателю необходимо определить и добавить конкретные сроки хранения серверных служебных данных, журналов и резервных копий, а также порядок исполнения запросов об удалении. В этом проекте такие сроки и гарантии не выдумываются. До утверждения этих сведений, итогового текста и доступного публичного HTTPS-адреса документ нельзя указывать как действующую политику в заявке на публикацию.
