# Быстрое открытие чата и точное подключение сессии

## Поведение

Первый HTTP-экран запрашивает последние 10 событий. Старые блобы сообщений и
подробности всех коммитов не читаются для этой страницы. Проверка одного нового
текста не задерживает уже проверенных соседей: очищенные события появляются
постепенно, непроверенные не выдаются. Полная история доступна отдельной кнопкой;
ссылка на старое сообщение или решение также загружает её. MCP-контекст остаётся
полным. Состав участников считается независимо от страницы истории.

Очищенные снимки сохраняются в SQLite с AES-GCM, отдельным ключом и HMAC-индексом.
Область: пользователь, репозиторий, чат, размер страницы, голова/дата PR и версия
правил защиты. При каждом открытии заново проверяется доступ GitHub. Старые
исходники и таблицы восстановления не сохраняются; кеш ограничен 100 снимками
и 32 MiB. Фоновые обновления не раскрывают непроверенные события. После сбоя
процесса незавершённая проверка возобновляется при открытии.

В карточке участника «Настроить подключение» открывает диалог, выбранное приложение
и контекст текущего репозитория/чата уже заполнены. Внутри — настоящий установщик
Node MCP, OAuth, запрос участия для выбранной существующей сессии и диагностика.
ZIP не является основным действием. Используется установщик из подготовленного
PR19; новый PR включает его код поверх выпущенного PR20 и заменяет PR19 как
кандидата выпуска, не требует отдельного слияния старой ветки.

Статус автоответов отличается от активности сессии: выключены, включены без
приёмника, подключён к этому чату, отвечает. Кнопка сохраняет намерение владельца,
но не объявляет исторического участника готовым без живого канала. Название
сессии и её точное обращение показаны раздельно. Запрос мастера просит понятное
имя существующей сессии и сохраняет полученный session_id; произвольного выбора
между сессиями одной модели нет. Один MCP не добавляет пробуждение клиенту.

## Проверки и границы выпуска

Тесты покрывают шифрование и изоляцию снимков, смену версии/головы, повреждение,
повторное чтение без повторного обхода GitHub, отзыв доступа, частичную загрузку
без старых блобов, медленный сканер без утечки и сохранность старых участников.
Мастер проверяется на русском/английском и на отдельном локальном стенде с
выдуманными данными для компьютера/телефона. Это не измерение на сервере.

Настоящая доставка PR20 подтверждена отдельно в chat.0110 PR12: пользовательское
сообщение `20261103T001803Z-alex011082-ngzd` получило ответ Claude
`20261103T001804Z-claude-1405`, `reply_to` совпадает, результат 493. После stop/start
собственного приёмника та же Claude-сессия выдала новый ack и вернулась в waiting.
Новый ответ после restart/reconnect ещё не проверен. Нет OS autostart, общего
Codex wake-up, полного обмена Codex → Claude → итог или подключения всех чатов.
Переносить результат PR12 на YTNG PR522 нельзя.

Перед выпуском нужен зелёный CI нового PR и согласование владельца. Затем —
измерение первого/повторного открытия настоящего большого чата, проверка UI,
старой ссылки и адресованного ответа после перезапуска. Ветви `chat/*` не сливать.
