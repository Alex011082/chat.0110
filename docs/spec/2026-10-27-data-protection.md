# Защита данных CHAT.0110

Согласовано владельцем: автоматически заменять секреты, контакты, реквизиты,
имена и адреса до очереди, GitHub и передачи ИИ. Оригиналы не сохранять.
Область: текст разговоров и их PR; не изображения и не произвольные кодовые PR.

## Реализация

1. Общий серверный сканер: правила для секретов/реквизитов, локальный GLiNER
   для русских и английских имён/адресов. Только очищенный текст и счётчики.
2. Закрыть запись HTTP/MCP/решений/Fork и выдачу старого содержимого. Сбой
   сканера останавливает публикацию. Служебные идентификаторы не изменять.
3. Настройки защиты в чате, предварительная проверка, отметки о заменах RU/EN.
4. Автоматические проверки, локальная модель, измерение на действующем сервере,
   сквозная проверка искусственными данными, независимое ревью.

## Границы

История Git не переписывается. Прямой push обходит CHAT.0110. Распознавание
свободного текста вероятностно. Защита включена всегда; настройки объясняют
категории и позволяют проверить текст, не предлагают небезопасный обход.

## Журнал выполнения

- Начало: чистые отслеживаемые файлы в codex/mentions-and-languages; assets/
  принадлежит предыдущей работе и не затрагивается.
- Решение: Python-процесс модели принадлежит существующему сервису, общается
  по stdin/stdout; отдельный сетевой сервис и платные API не нужны.
- Решение: счётчики замен восстанавливаются из маркеров в тексте; исходные
  значения и обратимые таблицы не сохраняются.

- Базовые правила и сквозные проверки HTTP/локального агента/MCP проходят:
  секреты заменяются до SQLite и GitHub; исходники не попадают в ответ API.
- Закрыты дополнительные обходы: merge PR агента и копирование старого чата
  отказывают при находках, поскольку слияние/копия сохранили бы исходник в Git.
- Измерение на сервере: RU 503 мс, EN 315 мс, emoji+EN 376 мс; холодная
  загрузка 11.95 с, пиковая память 2811 MiB. Это CPU, платные API не нужны.
- Исправлены ложная замена Claude, русские границы слов и квадратичный поиск
  email на длинной строке. Размер чанков модели проверяется по токенизатору.
- Независимое ревью: исправлены все три находки (env-префиксы, неизвестный
  frontmatter, пересечение NER). Для каждой был воспроизведён красный тест,
  затем зелёный. Неизвестные JSON-поля также проверяются перед копированием.
- Решение: некорректный/неизвестный frontmatter при merge/миграции отклоняется,
  а не переносится молча. Цена: старые файлы с нестандартными полями нужно
  отправить через API/MCP либо отдельно привести к протоколу.
- Процессу модели передаётся только минимальное окружение, без OAuth/GitHub
  секретов приложения. Веса закреплены по revision.
