# Общий удалённый плагин CHAT.0110

Основание: прямое поручение владельца 05.11.2026 в согласованной CheckAbout-сессии:
исправить общий remote-плагин вместе с этой сессией и подготовить публикацию для всех,
без установки на Mac; прежний codex и очередь сохранить, Active off, DNS не трогать.

Основной путь ChatGPT/Codex — общий HTTPS MCP и OAuth каждого пользователя.
Публичная директория пока не содержит опубликованного CHAT.0110: кандидат не подан.
Личная custom connection и развернутый сервер не равны публичной публикации.

На /connect по умолчанию нет npx/Node/stdio/Restart локального MCP. Локальный путь
остаётся только как отдельно выбранный расширенный вариант. Видимый дизайн сохраняется.
Для существующего участника копируется status-only запрос с точным session_id и
контекстом repo/chat и проверкой возвращаемых status id/author/alias; он не вызывает connect, rebind, set_auto_reply,
не создаёт другой alias и не запускает задания. Этот запрос отправляется именно
прежней сессии. Новый connect — отдельное явное действие для нового участника.
Ошибка/чужой ID/несовпадение автора останавливают сценарий без fallback.

Старый Apps-каталог (6 инструментов, pending без session_id) должен обновляться
штатным Refresh конкретной private connection. Публичный publisher Rescan — другой
процесс. Обходить схему и ослаблять серверную изоляцию нельзя. Общий пакет выбирает
author по фактическому host ChatGPT/Codex, не подменяет его ради доставки. Remote MCP
сам не гарантирует idle wakeup. Персональный plugin ID владельца не используется
как общая ссылка установки.

Новая версия кандидата 0.4.3, оба Codex manifest и review-status согласованы.
Подзаголовок <=30 знаков, описание <=4000. Включены 5 положительных и 3 отрицательных
реальных сценария review с критериями, без заявления, что они пройдены в reviewer
аккаунте. CI проверяет именно распакованный ZIP: версии, transport, отсутствие hooks/
локальных команд и конфигураций, metadata/cases/assets. Publisher identity/domain
verification, утверждённые реальные privacy/terms, reviewer account и видеодемо —
явный остаток; не подставлять фиктивные URL/учётки и не объявлять official.

Подготовка PR и CI разрешена; нового merge/deploy/submission/publication нет.
Ни текущая remote-сессия, ни очередь/OAuth/клиентская установка не меняются.
