# Мобильный чат и понятные статусы

**Цель:** сохранить утверждённые панели участника и действий; основной разговор
строится как в светлом дизайне, обе темы получают одинаковую мобильную геометрию.

**Основание:** владелец одобрил панели макета 05.11 и прислал шесть iPhone
скриншотов с перекрытым вводом, пустотой над клавиатурой и большим нижним рельсом.
Новые модельные вызовы, изменения OAuth/очереди и выпуск не входят в этот diff.

## Последовательность
- [x] RED в CI: viewport учитывает offsetTop, scroll/resize и очистку подписок;
  свёрнутый composer не содержит подключения/защиты/подсказок; короткие статусы
  зависят от delivery_ready, а не online; поиск репозиториев ограничен доступными.
- [x] AppFrame/lib/viewport.ts: видимое окно и его смещение, прокрутка только
  внутри приложения; PWA установка/обновление в меню вместо постоянной полосы.
- [x] Composer/ChatView/Menu/ParticipantsBar: общий компактный мобильный header,
  Sheet снизу для участника и действий; только поле/отправка внизу; защита и
  история заданий открываются из меню, актуальная ошибка/Stop остаются у ввода.
- [x] Rail/ChatList/RepoPicker: убрать нижний рельс на телефоне, перенести новый
  чат/дерево/настройки в шапку; выбор репозитория — поиск и недавние в Sheet.
- [x] Короткие RU/EN статусы: отвечает, получает обращения, приостановлен,
  нужно подключить. Точное обращение и диагностика доступны внутри участника.
- [x] GREEN CI: bun test, typecheck, build. Независимый review. Отдельно отметить,
  что CI не доказывает исправление настоящей клавиатуры Safari на iPhone.

## Границы проверки
Не терять черновик при открытии панели/смене клавиатуры; не показывать зелёную
готовность по одной недавней активности; не маскировать ошибку данных пустым
списком; ограничивать длинные меню доступной высотой; сохранять Stop для работы.
Масштабирование страницы не должно вызывать пересчёт компоновки под увеличенный
фрагмент. Статические страницы /connect также остаются прокручиваемыми внутри.

Проверки выполняются в CI; установка зависимостей, сборки и браузерные прогоны
на Mac не запускаются. Пользовательский незакоммиченный документ не включается.
