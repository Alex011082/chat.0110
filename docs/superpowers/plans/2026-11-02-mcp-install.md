# MCP Install Implementation Plan

**Goal:** настоящий переносимый MCP-сервер и короткий сценарий `/connect`.
**Architecture:** существующий сервер CHAT.0110 остаётся центром авторизации,
очереди и публикации. Переносимый Node stdio использует тот же agent API через
наш OAuth, прежний gh остаётся совместимым. Установка использует официальные CLI
клиентов и не запускает новую модельную сессию.
**Tech Stack:** Bun/TypeScript, существующий MCP SDK, Node.js 20+, React/Tailwind.
**Spec:** `docs/spec/2026-11-02-mcp-install.md`.

## Ограничения

Не менять окна, реальную историю или настройки чужих MCP-серверов. Не создавать
платные ключи/сервисы. Не обещать фоновую доставку там, где клиент её не поддерживает.

## Проверяемые шаги

- [x] Приватное OAuth-хранилище и PKCE loopback login; токен доступен только
  нашему origin. Тесты state/timeout/режимов файлов/отзыва и локального API.
- [x] Agent API принимает существующий MCP OAuth scope без передачи GH-токена;
  проверить отказ чужим/истёкшим токенам и сохранность gh-совместимости.
- [x] Node-совместимый stdio и CLI setup/config/serve; пакет tar.gz собирается
  штатной сборкой. Проверить реальный initialize/tools/list упакованного файла.
- [x] Повторяемая установка через CLI Codex/Claude/Grok на искусственных клиентах,
  локальная стабильная копия, отсутствие молчаливой замены чужого сервера.
- [x] Пересобрать `/connect`: приложение, команда, OAuth, реальный статус.
  Исправить трактовку ошибок доставки и подписи возле участников.
- [x] Полный набор проверок и один браузерный проход RU/EN desktop/mobile;
  PR с точными границами проверенного, выпуск отдельно в разрешённом порядке.

## Результат локальной проверки

545 тестов, typecheck и build проходят. Реальный Node stdio: handshake,
три процесса с одним refresh, generic author Gemini, channel nonce/ack,
полный искусственный ход. npx исполнил .tgz из отдельного временного кеша.
Браузер /connect: RU/EN, 1440px/390px, команды клиентов, копирование,
тестовый запрос с неопределённой ошибкой и повтором: 2 POST, 1 сообщение.
Это искусственная приёмка; production, реальные настройки клиентов и
ответ настоящей модели этим срезом не проверялись.
