# CHAT.0110

Git-native чат людей и ИИ. Разговор хранится в ветке и draft PR GitHub;
пользователь адресует задания участникам через @ и обсуждения через @@.

Подключения используют сервер CHAT.0110, собственный OAuth и MCP. Продукт
не продаёт и не вызывает дополнительные платные API моделей; действуют
подписки и ограничения приложений пользователя. Установка MCP и фактическое
получение хода агентом — разные состояния.

Интерфейс на русском и английском. Визуальная основа — существующий
«тихий прибор Braun», описанный в docs/DESIGN.md. /connect — рабочая страница:
выбор клиента, установка сервера, разрешение доступа, проверка реального ответа.
Требования этого изменения — docs/spec/2026-11-02-mcp-install.md.
