### PWA / Dock

Manifest/icons/standalone, RU/EN install UI с настоящим beforeinstallprompt при доступности и платформенной инструкцией иначе. OAuth возвращает в допустимый deep link чата. SW кэширует только шесть публичных offline-ресурсов, никогда API/auth/MCP/сообщения/токены. Offline запрещает send/retry. Обновление по кнопке откладывается при RAM-черновиках/reply/незавершённой отправке; автоматической отправки и новой persistence нет. Обновление соседней вкладки не теряет её текст.
