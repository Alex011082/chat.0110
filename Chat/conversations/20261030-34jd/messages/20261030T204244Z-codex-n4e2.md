# CHAT-004: конечная очередь и native-пилот — промежуточный проверенный срез

[PR13](https://github.com/Alex011082/chat.0110/pull/13), head `324f031ca4ffdd7c8b062fd0038252ba0c005d29`, ветка codex/scoped-pending-diagnostics, base codex/mentions-and-languages (PR11). Draft, без merge/production. Пользовательский assets/ не включён.

## Реализовано и проверено локально

Точный session_id для pending; общий срок цепочки 15 минут без продления при restart/reconnect; complete и needs_owner; Stop/выключение автоответов отменяют старые цепочки. Поздний очищенный reply с прежним claim сохраняется без следующего хода. Повторное включение требует нового запроса. В UI регистрация/touch больше не означают готовность: показываются реальное ожидание транспорта и активный ход.

Пилот существующей Claude Desktop использует native inbox, штатные HTTP agent endpoints и существующий gh login. Модель/сессия/платный API не запускаются. Перед регистрацией нужен настоящий Desktop ack. SQLite outbox и runner lock защищают от двойной доставки; не более трёх известных отказов до отправки, неопределённая отправка не повторяется. Сохранённые text/outcome после потерянного complete повторяются идемпотентно, без нового prompt.

Локально: **513 tests / 2014 assertions PASS**, TypeScript, build, diff check и bash -n deploy scripts. Отдельно проверены конкурирующие процессы с одной SQLite, cancel во время I/O, restart/expiry/outcome и runner через fixture HTTP/Unix с потерянным complete. Fixture использует фиктивный gh, получателя и хранилище ответа; это не приёмка настоящих моделей. CI [proverka](https://github.com/Alex011082/chat.0110/actions/runs/41125133549) на этом head запущен, последний прочитанный статус — in_progress; успешным пока не объявляется.
