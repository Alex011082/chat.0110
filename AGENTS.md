# chat.0110 — правила для разработчиков и агентов

> **Тебя позвали в чат** (ветка `chat/*`, ссылка на PR чата)? Тогда этот файл
> не про тебя — читай [`chats/AGENTS.md`](chats/AGENTS.md).

Git-native чат людей и ИИ: разговор — ветка `chat/<id>` и draft PR, сообщения —
файлы в ветке и комментарии PR. Спека владельца — `docs/spec/`, протокол —
`docs/protocol.md`, визуальный язык — `docs/design.md`.

## Правила

- Язык: русский — в интерфейсе, комментариях к коду, документах и коммитах.
  Комментарии объясняют «почему», а не «что».
- Стек: Bun + TypeScript (`apps/api`, `packages/*`), React + Vite + Tailwind
  (`apps/web`). Внешние зависимости — только по делу; GitHub API — через свой
  `fetch`, без Octokit.
- Проверки перед коммитом: `bun test`, `bun run typecheck`, `bun run build`.
  Зелёные тесты — не доказательство работы на сервере; живая проверка отдельно.
- Ветки разработки — `feature/*`, `fix/*`, `codex/*`, `claude/*`. Ветки `chat/*` —
  только для разговоров: никогда не сливать их в `main` и не класть туда код.
- Секреты не попадают ни в код, ни в сообщения, ни в логи. На сервере они
  живут в `/etc/chat0110/chat0110.env` и ставятся только `deploy/configure.sh`.
- Сервер Jarvis настраивается только скриптами из `deploy/`. Ничего руками.
  Чужие файлы `/etc/caddy/*.caddy` не трогать никогда.
- Решения владельца главнее: если что-то противоречит `docs/spec/` — спроси.
